**A CLI you start by hand in a tab gets the same chat cover as a launched agent.** Type `claude` (or any supported agent CLI) in a shell tab, local or remote, and the tab gets the Chat | CLI switch, the held-output count and the needs-you flag. A dashed ring on the Chat segment says the chat will cover the tab, and it does once the CLI first reaches Ready. A CLI CodeSense can only see as a process keeps the switch and stays on the CLI. If you flip to the CLI, the tab stays there for its life, through the CLI exiting and a new one started in it. The tab wears a lettered face and a dashed "by hand" label, and its chat says why it has no earlier thread.
