**Tile arrangements save themselves, and windows and agents share them.** With the tiles preview on, moving, resizing or closing a tile saves the arrangement to its private file with no Save step, and a window opens each arrangement from that file. Two windows and an agent can change one arrangement at once: a window's change made on an older copy is applied on top of the newer one, and when an agent changed the same tile first, the window shows the agent's change so you can repeat yours. A change saved elsewhere shows in an open window at once, and a window keeps up to three pinned tiles, saved under its name in the org you pinned them in.
