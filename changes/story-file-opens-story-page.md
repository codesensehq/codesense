**A story file opens its team's story page.** A team can name a story page in `teams.yml` (`story_page:`, relative to its content). An `.md` file whose front matter says `type: story`, `bug` or `spike` then opens that page in the file's own tab, with the file named in the page's URL fragment, from the Files tree, a pipeline card, a link in a viewer or an inbox file chip. Opening it again focuses the tab. A team without the setting opens such a file as markdown, with a line saying why.
