**A page's `kit.chat` working row shows what the lead is writing.** With the working row on (`activity`), the row shows the live lead's latest prose from its session as it streams, one line long, with the whole chunk on hover. It clears when the turn ends or the lead's next message arrives. Screen readers hear "Working…" once, not every chunk. A session the host can't stream (another machine or another CLI) shows the row as before.
