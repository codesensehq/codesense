**The pin tool, page contract and pins result schema list each pin's message.** Each pin carries `message` with `from`, `createdAtMs`, `text` (the first 2,000 characters of the pinned message) and, when the sender set them, `contentType` and `summary`. The pin tool text, the page contract, the pins example in the primitives reference and the verb schema now say so.
