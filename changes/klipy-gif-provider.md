**GIF search can use KLIPY.** Settings → Messaging now offers Off, GIPHY or KLIPY. Each provider keeps its own key in your OS keychain and its own production mark, so switching keeps both. With search Off, a Keys row shows each saved key and can remove one. With KLIPY, each GIF an agent sends is registered with KLIPY's share call, which carries the words the search used and a random id made on this computer for the install and key; turning search off or removing the key deletes that id. KLIPY is the default provider on a fresh install. `gif_search`, `gifSearch` and `gifPicked` name the provider, and GIF ids can be up to 128 characters.
