**Pin at the cap by choosing which pin to replace.** When an agent's chat already shows 3 pins, a message's Pin… opens a short list of the pins under it. Choose one, and the message takes that pin's place; one Undo puts both back. A pin the agent added while the list is open must be looked at before it can be replaced, and a pin that leaves meanwhile turns the list into a plain Pin.
