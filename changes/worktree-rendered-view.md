**See worktree docs rendered.** Markdown, images and canvases in a source worktree, and the HTML dashboards your team's context brings into it, have a Rendered | Source switch, so story docs and dashboards read as they render, with `window.codesense` working in the dashboard. A dashboard renders only when it came from your team's context, and never reaches the outside network; the repo's own HTML opens as text. Images and canvases open rendered, as do story docs and dashboards; the app remembers your choice per file type, separately for team context and the rest of the worktree. ⇧⌘V switches between the two, and a canvas you draw on saves into the worktree.
