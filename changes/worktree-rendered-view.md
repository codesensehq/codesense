**See worktree docs rendered.** Markdown, HTML dashboards, images and canvases in a source worktree have a Rendered | Source switch, so story docs and dashboards read as they render, with `window.codesense` working in the dashboard. Images and canvases open rendered, as do story docs and dashboards; the app remembers your choice per file type, separately for team context and the rest of the worktree.
