**Export to PDF explains itself where it can't work, and code fonts on Windows and Linux.** Where this OS can't export a document to PDF, Export to PDF in the tab menu and the file tree's right-click menu is disabled with a note saying why, Settings > Shortcuts shows that note in place of its shortcut, and Ctrl+Shift+E is free for another shortcut.
