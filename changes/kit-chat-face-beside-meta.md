**A `kit.chat` face no longer reads its initials before the sender's name.** With `faces` on, the avatar now sits beside a run's meta line instead of inside it, and is hidden from screen readers, so the line reads only "Story lead · 1:59 PM". An image face no longer repeats the name as its alt text. When the face's name differs from the line's (a person's name beside a role word), a screen reader hears it once, before the line. It looks the same as before.
