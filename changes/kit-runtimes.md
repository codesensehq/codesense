**Dashboards can list the installed agent CLIs.** `kit.runtimes()` returns the CLIs on this Mac in the order a page should offer them: the last used one, then Claude, Codex and OpenCode. Hermes is listed but never picked for you. While the app is still looking for the CLIs on first launch, it says so, so a page can wait instead of showing none.
