**Reveal and Open file work on Linux.** Reveal opens the folder in your file manager, an unreadable machine file opens in your default text editor (never its own handler), and terminal detection lists the terminals installed instead of Terminal; on macOS, Reveal selects the folder in Finder rather than opening it, and opening iTerm2 or Terminal passes the folder as an argument and refuses one whose name holds a backslash or a control character.
