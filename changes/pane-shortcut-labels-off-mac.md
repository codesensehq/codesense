**Notes, inbox and agent list name your keys on Windows and Linux.** Their shortcut hints read `Ctrl+⏎`, `Ctrl+Alt+⏎` and `Alt+click` instead of macOS symbols, Notes says your notes are kept on this computer, Ctrl+Alt+Enter pastes from Notes' send menu, and an agent on this machine never shows a machine name, whatever the machine is called. Panes can name keys and this machine the same way with `codesense.formatKeys`, `fillKeys`, `formatModifierClick`, `localMachineLabel` and `localMachinePhrase`.
