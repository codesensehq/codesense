**Notes, inbox and agent list name your keys on Windows and Linux.** Their shortcut hints read `Ctrl+⏎`, `Ctrl+Alt+⏎` and `Alt+click` instead of macOS symbols, Notes says your notes are kept on this computer, Ctrl+Alt+Enter pastes from Notes (AltGr+Enter doesn't), and an agent on this machine never shows a machine name, whatever the machine is called. On macOS the hints now match the rest of the app: `⌘↵` reads `⌘⏎`, `⌥⌘↵` reads `⌘⌥⏎`, Option-click reads `⌥-click` and Option+↑ reads `⌥↑`. Panes can name keys and this machine the same way with `codesense.formatKeys`, `fillKeys`, `formatModifierClick`, `localMachineLabel` and `localMachinePhrase`.
