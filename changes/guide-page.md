**The CodeSense setup page.** A bundled docs page mounts the shared chat (`kit.chat`) in its page layout for the setup guide: consent cards that show their class, suggested prompts from the agent's `Next:` line, an activity line and Stop, a runtime chip with the installed CLIs, a `⋯` menu (what I've set up, copy the setup summary, clear the conversation), an empty state when no agent CLI is installed and a sign-in notice with the CLI's own login command. Its hash joins the pages that may open a team agent (`guide-claude`, `guide-codex` and `guide-opencode` may now be launched by those pages), and the guide pack asks for `kit.chat` version 1.
