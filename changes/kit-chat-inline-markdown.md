**`kit.chat` draws simple formatting in messages.** A message's `**bold**`, `*italic*` or `_italic_`, and `` `code` `` now show as such, instead of their raw markers. Only that small set is read. Names like `snake_case`, sums like `2*3*4`, and markers left open stay as written, and a tag in a message is still shown as text. HTML messages are unchanged.
