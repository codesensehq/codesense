**File diffs show their keyboard focus, and say why an image won't draw.** The Diff mode and side switches now show a visible focus ring on the segment you're on; before, it was clipped away. When a changed image can't be drawn, the switch presses Source, matching what's shown. An image still being read shows a loading line instead of the final message. An image whose copy failed to read keeps Side by side disabled with the reason, rather than offering text diff modes. A side closed for opening another page is announced politely, and the team-edit diff's labels use one apostrophe style.
