**The terminal server's tray icon and keep-running-in-background on Linux.** With the AppIndicator library installed, **Show terminal server in the tray** puts the terminal server's status, Open CodeSense, Restart, Stop or Start and Quit in the tray, and while it shows, closing the window keeps CodeSense running and the icon's menu brings it back; with no tray icon, closing the window quits as before.
