**A page's `kit.chat` can replace a pin at the cap, as an agent's chat overlay does.** With `onPin.replace`, Pin at 3 of 3 becomes Pin…, which opens a chooser under the message. It lists the pins in order, with who pinned each and when. Choose one with the arrow keys and Enter, or a click, and the message takes that pin's place. One Undo brings both back. A pin the agent adds while the chooser is open is marked New and must be chosen twice. If a pin leaves, the chooser offers a plain Pin. The page's pins can mark the pin the current row would replace (`onPin.mark`).
