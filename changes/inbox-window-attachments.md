**Images and file links in the Inbox window.** Messages with an image now show it inline, with a lightbox, or say why it is not shown (waiting to load, media turned off, or failed) and offer Load or Retry. With Reduce Motion on, a GIF or WebP shows a still frame and plays only when you press Play. A message that names a file ends with a chip that opens the file in a viewer tab, as the Inbox pane does.
