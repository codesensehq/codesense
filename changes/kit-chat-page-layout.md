**`kit.chat` can lay out as a full page and show a working row.** `layout.variant: 'page'` marks the chat column (`data-variant="page"`) for a page's own full-page styling, and `activity` adds a row under the thread that shows the page's own line or the peer's current step while it runs. Both are off by default, so the story chat is unchanged.
