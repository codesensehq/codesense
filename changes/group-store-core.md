**Saved tile arrangements have one private home.** With the tiles preview on, CodeSense keeps each saved arrangement as its own file in Private, for the org and profile it was saved in, and never syncs, pushes or shares it. A save never silently replaces a newer one, a damaged or newer file is listed as "can't be read" and left as it is, and with the preview off nothing is written.
